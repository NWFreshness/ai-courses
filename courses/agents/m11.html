Glossary

A2A (Agent2Agent)
A protocol for agents to discover each other through agent cards and exchange tasks over HTTP.
Agent
A system in which a model directs its own process, choosing tools and steps in a loop until it decides the goal is met.
Agent card
A JSON description of an A2A agent's name, skills and endpoint, published at a well-known URL.
Agentic RAG
Retrieval where the agent decides what to store and when to search, using a vector store as a tool.
Agents as tools
Wrapping an agent so another agent can call it and get its result back, keeping the caller in control.
Checkpointer
In LangGraph, the component that saves the graph's state after every step, keyed by thread.
Context engineering
Deciding everything a model sees when it acts: instructions, memory, retrieved documents, tool results and live data.
Crew
In CrewAI, a set of agents and tasks run by a process: sequential or hierarchical.
Evaluator-optimizer
A workflow where one model's output is checked by another, and revised until it passes.
Guardrail
A check on an agent's input or output that can stop a run when it trips.
Handoff
Passing control of a conversation from one agent to another, which then continues it.
Hierarchical process
A crew run in which a manager agent delegates tasks and reviews results.
Human in the loop
Pausing an agent for a person's approval, edit or rejection before an action, then resuming.
Interrupt
In LangGraph, a pause that saves state and returns control to the caller until resumed with a Command.
MCP (Model Context Protocol)
An open protocol connecting AI applications to tools, resources and prompts served by MCP servers.
MCP host, client, server
The application; its per-server connection; and the program exposing capabilities.
Middleware
In LangChain agents, code that runs before or after model calls or around tool calls.
Orchestrator-workers
A pattern where a coordinating model decides subtasks at run time and delegates them.
Prompt injection
Instructions hidden in content an agent reads, aimed at making it act against its user.
Reducer
In LangGraph, a function that says how a state field combines old and new values, such as add_messages.
Resource (MCP)
Data an MCP server exposes for reading, identified by a URI.
Session
In the Agents SDK, stored conversation history replayed across runs.
Span
One timed step inside a trace: a model call, a tool call, an agent turn or a handoff.
stdio / Streamable HTTP
MCP's two transports: a local subprocess over standard input and output, or a remote server over HTTP.
Structured output
A model response constrained to, and validated against, a schema such as a Pydantic model.
Tool
A function an agent can ask to run, described to the model by a name, description and argument schema.
Trace
A record of one run: every model call, tool call and handoff, with timing.
Workflow
A system where models and tools follow code paths written in advance.
