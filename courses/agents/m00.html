A 6-week course · 10 modules · a working agent every week

Agentic AI, from the loop up

An agent is a model running in a loop, choosing tools to reach a goal. You'll write that loop by hand first, so nothing later is magic, then rebuild it with five agent frameworks, connect it to the world with the Model Context Protocol, and finish with a team of autonomous agents that trade on a simulated market while you watch.

Before you begin

You should be comfortable writing Python, calling an LLM API and reading JSON. If calling a model and handling a tool call are new to you, work through Weeks 1 and 2 of the LLM Engineering course first. Some async Python helps from Week 2; Module 0 has a short primer. After this course, Harness Engineering goes deeper on making agents dependable in production.

How each module works

  1. Objectives say what you'll be able to do.
  2. The project box lists what you'll build and the steps.
  3. The lessons explain the ideas with short code you can type and run.
  4. Pitfalls, takeaways, a quiz and an exercise close the module, followed by references.

Agents are easier to understand by watching them work than by reading about them. Run every example with tracing or logging turned on, change one thing, and run it again. Progress is saved in this browser.

Where this syllabus comes from

The week-by-week structure and projects follow Ed Donner's open agents repository, which accompanies his course on agentic AI. This course teaches the same subjects in its own words and code, so you don't need the repository to follow along; each module links to the matching folder if you want a reference implementation. Written in November 2026. Agent frameworks change quickly: where a version matters, this course says which one it was written against.
