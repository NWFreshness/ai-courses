Module 0 · before Week 1 · 1–2 hours

Set up your workshop

Most early frustration with LLM projects is environment trouble, not AI. An hour spent on a clean project, a reproducible Python environment, safely stored keys and a local model means every later week just runs.

By the end of this module you can

  • Create a Python project with uv and run notebooks and scripts in it.
  • Store API keys in a .env file, or avoid paid keys entirely with Ollama.
  • Diagnose the handful of problems behind most setup failures.
  • Estimate what the course will cost and keep it near zero.

Project: a working workshop

  1. Install git, an editor with Jupyter support (VS Code or Cursor, with the Python and Jupyter extensions), uv and Ollama.
  2. Create the project and its environment (commands below).
  3. Create a .env file with the keys you'll use, and a .gitignore that lists it.
  4. Pull a small local model and make one test call to it, and one to a frontier API if you have a key.
  5. Set a monthly spending limit on every paid account.

Cost: free. Paid API keys are optional throughout.

Create the project

Open the folder in your editor, create a notebook, and choose the .venv interpreter as its kernel. With uv you never activate the environment by hand: uv add replaces pip install, and uv run script.py replaces python script.py. Later weeks add a few packages (for example xgboost, modal, feedparser); add them when you need them.

The .env file

Start every notebook or script with from dotenv import load_dotenv; load_dotenv(override=True). That reads the file into environment variables, and the client libraries pick up their keys automatically. Three details cause most "key not found" errors: the file must be named exactly .env (not .env.txt), there's no space around the equals sign, and the file has to be saved.

Why keys live in .env and not in code

Notebooks get shared, pushed and pasted. A key typed into a cell ends up on GitHub sooner or later. A .env file listed in .gitignore stays on your machine. Treat it like a password file, turn auto-recharge off, and set a monthly limit on every paid account.

A first test

Set CHEAP_MODEL to the smallest current model from your provider. Run it with uv run test.py.

What it costs

The reference course reports that the whole eight weeks need no more than a couple of dollars of API calls if you use each provider's cheapest models, and that paid APIs are optional thanks to Ollama and free tiers such as Gemini's and OpenRouter's free models. A few optional full-size runs cost more: rewriting 800,000 product records in Week 6 (under $30 with a fast, cheap provider; under $1 for the 20,000-item version) and the full fine-tuning run in Week 7 (about $10). The smaller versions teach the same lessons.

When it doesn't work

  • Corporate networks: VPNs, firewalls and TLS inspection cause SSL errors and blocked downloads. Try a phone hotspot to prove whether it's the network.
  • Windows: the 260-character path limit, file permissions, and missing Microsoft C++ Build Tools are the usual culprits.
  • Mac: install the Xcode command-line tools (xcode-select --install) if compilers are missing.
  • Name errors in a notebook almost always mean a cell above wasn't run. Restart the kernel and run from the top.
  • A model stops working: providers retire models every few months. Swap in the closest current model from the same provider.
  • Ollama doesn't answer: visit http://localhost:11434; if it isn't running, start it with ollama serve. Stick to models of about 3 GB or less on a laptop.

Takeaways

  • One uv project, one .venv kernel, dependencies added with uv add.
  • Keys go in a file named exactly .env, listed in .gitignore; Ollama means you can do almost everything for free.
  • Expect a few dollars of API spend, plus optional extras for full-size runs in Weeks 6–7.

Check your understanding

Your script says the API key isn't found, but you created the file. What's most likely?

The loader only looks for a file named exactly .env, and only sees what's been saved.

How do you add a package to this project?

uv add updates pyproject.toml and the lock file and installs into the project's .venv, so the project stays reproducible.

You'd rather not pay for any API. What's the plan?

Every OpenAI-style call in this course can point at Ollama's local endpoint instead, at the cost of smaller, less capable models.
