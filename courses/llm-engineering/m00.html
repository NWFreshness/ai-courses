LLM Engineering, week by week

Ed Donner's llm_engineering repo is an eight-week, project-driven course that ends with an autonomous agent that finds bargains and sends them to your phone. This companion sits beside it: for each week it explains the ideas behind the notebooks, maps which file does what, flags where people get stuck, and gives you checks and exercises so the material sticks.

How to use this with the repo

The repo is the course; this is the study guide. The labs are Jupyter notebooks, and the author's advice is to run every cell, look at what comes back, and change things. This guide doesn't replace that. Keep both open: notebooks in Cursor or VS Code, this page on a second screen or your phone.

  1. Before a week, read the module's objectives and the notebook map so you know where you're heading.
  2. During the week, work through the notebooks in order. Use the concept sections here when something in a notebook feels like magic.
  3. After the week, take the quiz, do the exercise, and look at the "Go further" section. Several point into the Harness Engineering course, which picks up where this one stops.

A note on currency

This guide was written in November 2026 against the repo as it stood then (it's updated often). Model names in the notebooks change as providers retire models; the author's guidance is that if a model stops working, you swap in the nearest current one from the same provider. This guide talks about kinds of models rather than specific names wherever it can, so it ages more slowly than the code.
