LLM Engineering, week by week

Learn to build products on large language models, from your first API call to a fine-tuned open model running inside an autonomous agent. Each week teaches the ideas, then walks you through building a working project of your own, with checks and exercises to make it stick.

How each module works

  1. Objectives tell you what you'll be able to do.
  2. The project box describes what you'll build that week and the steps to get there.
  3. The lessons explain the ideas, with short code you can type and run.
  4. Pitfalls, takeaways, a quiz and an exercise close each module, followed by references.

Type the code rather than copying it when you can, run it, and then change it. Keep a short log per week of what surprised you and what broke. Progress is saved in this browser.

Where this syllabus comes from

The week-by-week structure, the projects and the published results follow Ed Donner's open llm_engineering repository, which accompanies his course of the same name. This course teaches the same subjects in its own words and code, so you don't need the repo to follow along; each module links to the matching folder if you want to see a reference implementation. Written in November 2026. Model names change often; where this course names a model, swap in the current equivalent from the same provider.
