Glossary

Adapter (LoRA)
A small set of trainable matrices added beside a frozen model's layers; the output of fine-tuning with LoRA.
Base model / instruct model
A model trained only to continue text, versus one further trained to follow chat instructions.
Batch API
A way to submit many requests to be processed asynchronously at a lower price.
Chat template
The model-specific format, with special tokens, that wraps a conversation into model input.
Chunk
A passage of a document stored and retrieved as one unit in RAG.
Context window
The maximum number of tokens a model can take in one request, including the conversation so far.
Embedding
A vector representation of text in which similar meanings are close together.
Ensemble
A combination of several models' predictions, here a weighted average.
Frontier model
One of the most capable models available, usually closed and accessed by API.
Gated model
A Hugging Face model you can download only after accepting its license.
Hit rate
The share of test questions for which at least one relevant chunk was retrieved.
LLM as judge
Using a model to grade another model's output against criteria or a reference answer.
MRR
Mean reciprocal rank: the average of 1 / (position of the first relevant result).
nDCG
Normalized discounted cumulative gain: rewards relevant results more the higher they rank.
OpenAI-compatible endpoint
Another provider's API that accepts the same request shape as OpenAI's Chat Completions.
Prompt caching
Provider-side reuse of an identical prompt prefix, billed at a discount.
QLoRA
LoRA fine-tuning with the frozen base model held in 4-bit precision.
Quantization
Storing model weights at lower precision (for example 4-bit) to cut memory use.
RAG
Retrieval-augmented generation: retrieve relevant context and include it in the prompt.
Reasoning effort
A setting on reasoning models that controls how much they think before answering.
Recall@K
For one test, relevant chunks in the top K divided by all relevant chunks.
Reranking
Reordering retrieved results by relevance, often with a model, before using the best few.
Structured outputs
Constraining a model's reply to a schema so it parses into a typed object.
System prompt
The instruction that sets the model's task, tone and rules for a conversation.
Token
The unit of text a model reads and writes; what context limits and pricing are counted in.
Tool calling
The model asking your code to run a described function and return the result.
