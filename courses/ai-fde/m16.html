Glossary

ADLC
The agent development lifecycle (discovery, R&D, development, implementation, maintenance); also used for building code with coding agents.
Agentic RAG
Retrieval where the agent writes its own queries and searches as often as it needs.
AgentCore
Amazon Bedrock AgentCore: AWS's managed services for agents, including Runtime, Gateway, Identity, Memory and Policy.
Cedar
A policy language for permit and forbid rules; a forbid always overrides a permit.
Checkpoint
A saved copy of a graph's state after a step, under a thread ID.
Cohen's kappa
Agreement between two raters beyond what chance would give; 0 for a constant answer.
Context layer
Business knowledge served to agents with meaning, practice, permission and provenance.
Cost of mistakes
A business cost per kind of error, agreed with the client, summed over a run.
Durable execution
Running work so it can stop partway and carry on later from where it was.
FDE
Forward deployed engineer: an engineer embedded with a client to deliver AI into use.
Gateway
A service in front of APIs, tools or models that adds credentials and enforces rules.
Harness
Everything around the model that makes an agent work: context, workflow, state, subagents, permissions, observability.
Held-out set
Evaluation data the system being improved never sees, used to decide what to keep.
Idempotent
Safe to repeat: doing it twice has the same effect as doing it once.
Interrupt
A pause in a graph for outside input, resumed with Command(resume=...).
Lethal trifecta
Private data, untrusted content and external communication in one agent.
Mixture of experts
A model that routes each token through a few expert blocks, so only some parameters are active.
Namespace
A path that scopes memory records, such as one per customer.
Noise
How much a score varies between runs of the same version; changes smaller than it mean nothing.
Pareto front
The options no other option beats on every measure at once.
Prompt injection
Text in an agent's input written to make it act against its instructions.
Quantization
Storing model weights in fewer bits to save memory and speed up generation.
Send
LangGraph's way to start one node run per item, for fan-out.
Straight-through rate
The share of claims the agent finishes without referring them to a person.
Swarm
Many agents working in parallel on independent pieces of work.
