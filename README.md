# Harness Engineering: a field course

A 12-module course on building production-grade agent harnesses: the loop, tools, context, guides and sensors, long-running agents, multi-agent orchestration, safety, durability, observability and evals, plus a capstone project. Researched November 2026 from primary sources (OpenAI, Anthropic, LangChain, Manus, Cognition, Thoughtworks/martinfowler.com and others), which are linked in every module.

**Read it:** https://nwfreshness.github.io/harness-engineering-course/

It's a single self-contained page (`index.html`) with no external dependencies. It works on phones, saves progress in your browser, and respects reduced-motion settings.

## Editing

The page is built from the fragments in `src/`:

| File | Contents |
|---|---|
| `src/00-head.html` | `<head>`, all CSS, sidebar and top bar |
| `src/m00.html` | Start page (the course map is generated by `build.py`) |
| `src/m01.html` … `src/m12.html` | Modules 1–12 |
| `src/m13.html` | Checklist, glossary and sources |
| `src/99-tail.html` | Navigation, quizzes, progress, animation scripts |

After editing, rebuild:

```sh
python3 build.py      # writes index.html
```

Commit both `src/` and `index.html`. The GitHub Actions workflow in `.github/workflows/pages.yml` also rebuilds and deploys on every push to `main`.

## GitHub Pages setup (one time)

Repo **Settings → Pages → Build and deployment → Source: GitHub Actions**. The next push to `main` (or a manual run of the workflow) publishes the site.
